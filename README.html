AI Release Management

A weekly email: which AI models you use, which are retiring, who and what is affected, and what to swap to — plus new features and bundle changes.

5 steps~10 minutesSnowsight onlyCortex Code automationPrompt-based

Setup

1
Snowsight · 1 min

Get the Snowflake Documentation listing

Data Products → Marketplace → search Snowflake Documentation → Get. Keep the name SNOWFLAKE_DOCUMENTATION.

Get
2
Snowsight · 1 min

Sign in as the account that will run it, and verify emails

The automation runs as the user who creates it. Sign in to Snowsight as your service / automation user. It must be able to sign in to Snowsight.

Every recipient must be a Snowflake user with a verified email (Settings → Profile).

3
SQL worksheet · ACCOUNTADMIN · 2 min

Run setup.sql

Paste it into a worksheet, edit the recipient list and the role name, then Run All. It creates one email channel and grants. That’s all.

ALLOWED_RECIPIENTS = ('person1@company.com', 'person2@company.com')
GRANT ... TO ROLE SVC_ROLE;
4
Cortex Code in Snowsight · 5 min

Paste one message into Cortex Code

Open Cortex Code (bottom-right of Snowsight). Paste all of COCO_PASTE.txt after editing the two marked lines: timezone and recipients.

Cortex Code creates the automation, runs one test (you get the email), then starts the weekly schedule. Answer Yes when asked.

Cortex Code
You: Create a Cortex Code automation for me… AI_RELEASE_MANAGEMENT…

Cortex Code: Created paused. Test run sent the email. Start the schedule? Yes
5
Inbox · done

Check the inbox

Everyone on the list gets the report now and every week after that.

To change anything (sections, wording, lookback, recipients), edit the plain-English prompt in Cortex Code: “Update AI_RELEASE_MANAGEMENT prompt: …”. No code to maintain. For multiple accounts, repeat steps 1–4 in each.
