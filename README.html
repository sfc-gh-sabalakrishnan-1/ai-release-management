A weekly email: which AI models you use, which are retiring, who and what is affected, and what to swap to — plus new features and bundle changes.

1
Snowsight · 1 min

Get the Snowflake Documentation listing

Data Products → Marketplace → search Snowflake Documentation → Get. Keep the name SNOWFLAKE_DOCUMENTATION.

Already have it? Skip to step 2.

2
Snowsight · 1 min

Verify the email address that will receive the report

Click your name (bottom-left) → Settings → Profile → Email → verify. Every recipient must be a verified Snowflake user.

Settings › Profile
Email   you@company.com   ✓ Verified
3
SQL worksheet · ACCOUNTADMIN · 2 min

Open setup.sql and edit 3 lines

Projects → Workspaces (or Worksheets) → + SQL file → paste all of setup.sql. Change only the top three lines:

SET recipients = 'you@company.com';     -- who gets the email (comma-separated, no spaces)
SET warehouse  = 'COMPUTE_WH';          -- any XS warehouse
SET schedule   = 'USING CRON 0 8 * * MON America/New_York';  -- Mondays 8am
4
SQL worksheet · 3 min

Select all → Run

Press Ctrl/Cmd + A, then Ctrl/Cmd + Enter. The last statement sends the first report. It takes about 2 minutes.

Results
Sent: AI Release Management - YOUR_ACCOUNT - 6 models at risk
5
Inbox · done

Check your inbox

The report arrives now and then every week on schedule. Nothing else to maintain.

Multiple accounts? Repeat steps 1–4 in each account. Each email shows its account name.
